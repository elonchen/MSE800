## User Use Case Diagram

The key actor is the user, the diagram includes use cases such as register, login, logout, View Wallets, Exchange Currency, and View Transaction. Its purpose is to show how users interact with the system to manage their funds and monitor exchange activities.

## Admin Use Case Diagram
The key actor is the admin, the diagram includes use cases such as View All Users, Manage Currencies, Manage Exchange Rates, View Exchange Rate History, and View All Transaction. Its purpose is to illustrate how administrators control currency settings, maintain exchange rate information, and oversee user transactions within the platform.

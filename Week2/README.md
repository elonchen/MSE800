## Summary
This project demonstrates how OOP concepts can be used to build a clean and structured Python program.

### 1. Class
- A class named `Calculator` is used to encapsulate all operations.

### 2. Methods
The class includes:
- `add()`
- `subtract()`
- `multiply()`
- `divide()`

### 3. Functions Used
- `get_numbers()` → gets user input
- `main()` → controls the program flow
